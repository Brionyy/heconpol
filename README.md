# 보건정치경제연구실 홈페이지(heconpol.org)

서울대학교 보건대학원 보건정치경제연구실 홈페이지의 원본입니다. 누구나 보는 화면은 이 폴더의 표 · 글로 만들고, 회원 칸은 로그인 서비스(Supabase, 서울 서버)가 맡습니다.

> 이 폴더는 **공개 저장소**가 됩니다. 회원 글 · 사진 · 메일, 업체에서 받은 DB, 비밀 열쇠는 절대 넣지 않습니다(`.gitignore`가 막는 목록).

| 사이트 이름 · 주소 · 설정 | `data/site.csv` | 설정 하나 |

- 표는 GitHub 웹 화면에서 표 모양으로 보이고, 엑셀 · 넘버스로도 열립니다. **저장할 때 'CSV UTF-8'**로 저장합니다.
- 글 파일 쓰는 법: 빈 줄로 문단을 나누고, `## 제목`, `- 목록`, `**굵게**`, `[글자](https://주소)`, 표는 `| 칸 | 칸 |`. HTML을 쓰면 글자 그대로 보입니다(안전을 위해).
- 표에 빈 칸이 있으면 만들기가 멈추고 **몇 번째 줄 어느 칸**인지 알려 줍니다.

## 이 컴퓨터에서 미리 보기

```bash
python3 build.py --local
python3 -m http.server 8790 --bind 127.0.0.1 --directory _site
```

표를 고치지 않고 다른 색 배치를 잠깐 보려면 `python3 build.py --local --palette 신뢰`(또는 `고급`)로 만든 뒤 브라우저를 새로 고칩니다. 다시 `python3 build.py --local`로 만들면 표에 적힌 배치로 돌아옵니다.

브라우저에서 `http://localhost:8790`을 엽니다. `--local`이면 회원 칸이 **시험용 가짜 로그인**으로 돌아갑니다(이 브라우저 안에만 저장, 바깥으로 아무것도 안 보냄). 가짜 계정은 로그인 화면의 '시험용 가짜 계정 보기'에 있습니다.

- 파이썬 3.12 이상이 필요합니다(다른 설치 없음).
- **화면 폴더 `_site`는 `build.py`만 만들고 손으로 지우지 않습니다.** `build.py`는 폴더째 지우지 않고 바뀐 파일만 고치며, iCloud 동기화에서 빼 두고(이 Mac에만 있음, 다른 Mac에서는 그 Mac에서 한 번 만듦), 다른 대화가 만드는 중이면 끝나기를 기다립니다. 폴더째 지웠다 다시 만들면 iCloud가 지난 판을 `index 2.html` · `about 2` 같은 사본으로 되살립니다(2026-10-27 19개). 시험은 임시 폴더에 만들어 미리 보기를 건드리지 않습니다(`--out <폴더>`).
- 만들 때 이 폴더에서 이름 끝이 ` 2` · ` 3`인 사본이 보이면 그 파일은 쓰지 않고 공개 화면에도 넣지 않은 채 이름을 알립니다. 원본과 비교해 필요한 고침을 원본에 옮긴 뒤 사본은 휴지통으로 옮깁니다(공개 저장소에도 안 올라가게 `.gitignore`에 적음).

## 안전 장치(2_보안검토.md를 따름)

- 모든 화면에 차단 규칙(CSP)을 걸었습니다. 화면 안에 코드를 쓰지 않고, 바깥 주소에서 아무것도 부르지 않습니다(글꼴 · 부품 모두 `assets/` 안). 첫 화면만 지구본 부품이 머리에 넣는 빈 꾸밈 글 두 가지(`''` · `:root{}`)를 지문으로 허용합니다(다른 꾸밈 글은 계속 막힘).
- 바깥 부품의 판 번호와 지문: `assets/vendor/VERSIONS.txt`.
- 회원 글은 마크다운으로 저장하고, 보여 줄 때 DOMPurify로 거릅니다(`assets/js/lab/render.js`).
- 글쓰기 편집기(`assets/js/lab/editor.js`)는 보이는 그대로 쓰고 저장할 때 마크다운으로 바꿉니다. 본문 그림은 우리 사진 칸에 다시 저장한 그림만 `lab:<경로>`로 적고, 바깥 주소 · data: 그림은 보여 줄 때 지웁니다.
- 사진은 올리기 전에 브라우저에서 긴 변 1600px JPEG로 다시 저장해 위치 정보를 지웁니다(`assets/js/lab/upload.js`).
- 회원 칸 권한은 서버 규칙(`supabase/migrations/`)이 막습니다. 화면에서 단추를 숨기는 것은 막는 장치가 아닙니다.

## 회원 칸 서버 규칙 시험

```bash
PGLITE_DIR=<@electric-sql/pglite 0.5.8 을 설치한 폴더> node supabase/tests/rls_test.mjs
```

진짜 Postgres(PGlite)에 규칙 파일(`supabase/migrations/`, 날짜 순)을 모두 올리고 등급(방문자 · 승인 대기 · 회원 · 관리자)마다 되는 일 · 막혀야 하는 일 77가지를 확인합니다(구성원 CV 주소 8가지 포함). 서버 게시판 목록이 `data/boards.csv`와 같은지도 여기서 봅니다.

## 아직 안 한 것

- 진짜 회원 칸 서버 연결(`assets/js/lab/api-supabase.js`): 연구실 Supabase 프로젝트를 만든 뒤.
- 공개(GitHub Pages): 교수님 승인과 연구실 GitHub 계정이 생긴 뒤. 설정은 `.github/workflows/pages.yml`에 준비만 해 두었습니다.
- 첫 화면 모양(V1 · V2b · V5b): 교수님이 고르신 뒤. 셋째 장면 3D 지구본(WHO 협력센터)은 연구자 요청으로 먼저 넣었습니다(2026-10-27).
- 첫 화면 둘째 장면의 보건대학원 사진(허락과 원본 파일을 받은 뒤), 넷째 장면 연구실 단체 사진(파일과 나온 분들 동의를 받은 뒤).
